# Cinemática de cosecha de maní

Animación Three.js dirigida por frames con Remotion. La composición principal es
`PeanutHarvestIntro` (15 segundos, 1920×1080, 30 FPS).

## Desarrollo

```bash
npm install
npm run studio
```

La iteración se realiza en Remotion Studio. No ejecutes el script de render hasta
que la pieza haya sido aprobada explícitamente.

## Validación

```bash
npm run check
```

## Exportación (solo con aprobación)

```bash
npm run render
```
